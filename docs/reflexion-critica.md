# Reflexion critica

## 1. Cual es la diferencia entre Agile y DevOps

Agile se enfoca principalmente en organizar el trabajo de desarrollo en ciclos cortos, con entregas incrementales y retroalimentacion constante. DevOps amplia esa vision porque conecta el desarrollo con operaciones, seguridad, pruebas, automatizacion y monitoreo.

En otras palabras, Agile ayuda a construir mejor el producto y DevOps ayuda a entregar, operar y mejorar ese producto de forma continua.

## 2. Por que Git es fundamental en DevOps

Git es fundamental porque permite controlar versiones, crear ramas, revisar cambios y recuperar estados anteriores del proyecto. Sin un sistema de control de versiones, seria dificil automatizar pruebas, auditar cambios o coordinar el trabajo de varias personas.

En DevOps, Git funciona como la base del flujo de trabajo: los commits registran la historia, las ramas separan el desarrollo y los Pull Requests permiten revisar antes de integrar.

## 3. Que problema resuelve la Integracion Continua

La Integracion Continua resuelve el problema de descubrir errores demasiado tarde. Cuando los cambios se integran sin validacion frecuente, los fallos se acumulan y se vuelve mas dificil encontrar su causa.

Con CI, cada push puede ejecutar pruebas automaticas. Asi se detectan errores rapidamente, se reduce el riesgo de romper la rama principal y se mejora la calidad del software.

## 4. Que es la observabilidad y por que mejora la operacion

La observabilidad es la capacidad de conocer el estado interno de un sistema a partir de datos como logs, metricas y trazas. Mejora la operacion porque permite detectar fallos, analizar rendimiento y responder a incidentes con informacion concreta.

En un sistema hospitalario, la observabilidad es importante porque ayuda a mantener disponibles los servicios criticos y a identificar problemas antes de que afecten gravemente a los usuarios.
